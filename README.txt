LUTE — homepage prototype (Figma "Homepage v1", node 55:2944)

Open index.html in Chrome, Edge or Firefox. Keep the folder structure: the page loads its videos and images from media/ and assets/.
If a browser blocks local videos, run a tiny local server in this folder (e.g. `python3 -m http.server`) and open http://localhost:8000.

index.html            the whole page (HTML, CSS and JS in one file)
media/                videos: hero (lute_sklep_t2_bw.mp4) + How it works steps (box, t-shirt, veggies)
assets/images/        posters and photos (hero, The problem cards, How it works posters, blog)
assets/logos/         Team logos (white, for the dark marquee)

Fonts: Fragment Mono loads from Google Fonts. Season Mix is used if installed; otherwise the page falls back to Newsreader.
The intro timeline panel (bottom right) is a prototype control and is not part of the design.
